# App Store text for the iPhone app

*English · [Deutsch](STORE.de.md)*

The first paragraph is the one that matters. The usual one-star pattern for
sync apps reads "does not update in the background" – this sentence before
the download costs a few installs and saves the rating. It is in the app as
well, but there it reaches the user only after the purchase.

## Description

Spind talks directly to your SFTP storage. There is no server that could
notify your iPhone about new files. Folders are current when you open them;
a pull-down in the Files app fetches the latest state right away. In the
background, iOS decides when Spind may look – that can take a while.

Spind turns your Hetzner Storage Box or any SFTP server into a drive in the
Files app: files take up space only once you open them, changes go back to
the server, deleted files and earlier versions can be restored. New photos
are backed up on request as soon as the app is open. Pairing happens by QR
code from the Mac; the connection uses SSH keys only. Open source, no
subscription, no third-party cloud in between.
